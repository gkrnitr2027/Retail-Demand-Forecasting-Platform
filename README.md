# 🛒 Retail Demand Forecasting

A Machine Learning web application that predicts retail product demand based on product and market-related features using an XGBoost regression model.

## Features

* Predicts product demand in real time.
* Interactive web interface built with Streamlit.
* Uses an XGBoost Regression model.
* Handles categorical inputs using Label Encoding.

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* XGBoost
* Streamlit
* Pickle

## Input Features

* Price
* Discount
* Inventory Level
* Promotion
* Competitor Pricing
* Category

## How It Works

1. Enter the product details.
2. Select the product category and promotion status.
3. Click **Predict Demand**.
4. The application predicts the expected demand using the trained XGBoost model.
